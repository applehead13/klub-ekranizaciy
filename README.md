# Клуб экранизаций

Учебный концепт сайта книжного клуба: читаем книгу, смотрим экранизацию, спорим.
Название клуба, адрес и все данные вымышленные, заявка на встречу никуда не отправляется.

**Сайт:** https://applehead13.github.io/klub-ekranizaciy/

Автор и дизайнер: Полина Гусева, Telegram: [@ppolinaguseva](https://t.me/ppolinaguseva)

## Что внутри
Статический сайт: HTML, CSS и JavaScript без сборки. Адаптивная вёрстка от 320 до 2560 px.

## Изображения
Все изображения созданы с помощью нейросети (сервис gptrf.ru) по референсам; это иллюстрации, а не фотографии реальных встреч.

## Шрифты
- **Anvyl**, Matt Cole Wilson и Dmitry Sivukhin (2018): бесплатно для личного и коммерческого использования, лицензия в `fonts/Anvyl-License.txt`. Оригинал: https://www.behance.net/gallery/60352025/ANVYL-A-Free-Font
- **Tenor Sans**, Denis Masharov: SIL Open Font License 1.1, лицензия в `fonts/TenorSans-OFL.txt`. Оригинал: https://fonts.google.com/specimen/Tenor+Sans

## Библиотеки
GSAP и ScrollTrigger (анимации), Lenis (плавная прокрутка), лежат в `js/vendor`.
